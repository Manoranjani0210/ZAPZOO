# ZAPZOO

A responsive, warm nude-red / terracotta mini-game website prototype.

## Run locally
1. Download `index.html`.
2. Open it in a browser (Chrome, Edge, Firefox, Safari).
3. No installation or build tools are required.

## Publish with GitHub Pages
1. Create a GitHub repository named `zapzoo`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The Pages URL will appear in Settings → Pages.

## Prototype notes
- The website includes all five game screens and a responsive warm cream / beige / muted terracotta theme.
- This is an early playable prototype, not the final production build. Some game mechanics are simplified and should be tested and refined before a public expo.
- The Spin the Chaos timer uses two minutes; the dare is voluntary.
- No accounts, names, analytics, or data collection are included.
